# MYRAA voice aur browser panel

1. Isi PC par MYRAA desktop app start karein. Inventory website isi PC ke Chrome/Edge mein kholkar MYRAA icon dabayen. Typed chat microphone ke bina bhi start ho sakti hai.
2. **Start voice** dabakar microphone permission allow karein. Voice apne-aap start nahi hoti.
3. Hindi, Hinglish ya English mein baat karein; language badalne par agle turn mein usi bhasha mein poochhein. MYRAA ko latest message ki language/script mein jawab dene ke liye configure kiya gaya hai.
4. Voice band karne ke liye **End voice** ya panel ka close button dabayen. Typed chat bhi live session ke saath chalti hai.
5. Product, size, SKU aur quantity ko saaf bolein. Inventory mein koi write/dispatch aaye to confirmation card par details dekhkar hi **Confirm change** dabayen; galat ho to **Cancel**.

MYRAA ki Gemini aur inventory MCP settings ke setup ke liye [MYRAA integration guide](MYRAA_INTEGRATION_HI.md) dekhein. Browser panel local companion se connect hota hai; companion ke bina browser-only voice/PC control available nahi hota.
